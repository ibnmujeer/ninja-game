==================================================
   NUMBER BUILDER: NINJA BRICK ACADEMY
==================================================

A free maths game for kids aged about 6 to 7.

Build with bricks. Count, add, take away, make
groups and share. Help your ninja hero beat
Rumble, a grumpy robot!

PLAY IT HERE:

    https://YOURNAME.github.io/ninja-game/

(Open that address on a computer, a tablet or a
phone. Nothing to install.)


--------------------------------------------------
HOW TO PLAY
--------------------------------------------------

  1. Open the address above.
  2. Tap  Play .
  3. Pick your hero.
  4. Pick a world.
  5. Answer the questions!

The game reads every question out loud.
Tap the speaker button to hear it again.

Get it wrong? That's OK! You get a hint and you
try again. There is no timer and no lives.

Get it right the FIRST time and you win a star.
Each world has 8 stars to win.

--------------------------------------------------
THE 5 WORLDS
--------------------------------------------------

    World 1  BRICK BUILDERS   (+)  adding
    World 2  RUMBLE ATTACK    (-)  taking away
    World 3  BRICK FACTORY    (x)  groups of bricks
    World 4  TREASURE SHARE   (÷)  sharing
    World 5  NINJA MASTER     (★)  a bit of everything

Each world has 8 missions. The first 4 use numbers
up to 10. The last 4 use numbers up to 20.

The game changes the questions as you play.
Tricky? The next one may be easier, or show bricks
you can count. Doing great? It gets a little
harder.


--------------------------------------------------
PLAY ON A PHONE OR TABLET
--------------------------------------------------

Open the address, then add an icon to your
Home Screen:

    iPhone or iPad (Safari):
      Share button  >  Add to Home Screen

    Android (Chrome):
      Three dots  >  Add to Home screen

You need internet to OPEN the game. Once it has
opened, it keeps working if the internet drops.


--------------------------------------------------
PLAY WITHOUT INTERNET  (ASK A GROWN-UP)
--------------------------------------------------

  1. On this GitHub page, click the green  Code
     button.
  2. Click  Download ZIP .
  3. Unzip it (right-click > Extract All).
  4. Open the folder and double-click  index.html .

Keep  index.html  and the  app  folder together,
or the game won't work.


--------------------------------------------------
FOR GROWN-UPS: TEACHER MODE
--------------------------------------------------

On the Home screen there is a small clipboard
button at the bottom. Hold it for about 2 seconds,
then answer the grown-up sum.

In teacher mode you can:

  * make classes and add children
  * see a class dashboard and each child's progress
  * read a short Weekly Learning Pulse
  * set "Special missions" for a child or a class
  * choose what a child practises next
  * run a 12-question Ninja Check before and after
    learning, and compare the scores
  * export data (JSON and CSV) and import it back

The sum keeps children out. It is not a password.
Words like "possible pattern" are clues, not a
diagnosis.


--------------------------------------------------
FOR GROWN-UPS: SAVING AND PRIVACY
--------------------------------------------------

  * No accounts. No login. No ads. No tracking.

  * Everything is saved in the web browser on the
    device you play on. Nothing is sent to GitHub
    or anywhere else.

  * Each device and each browser has its own saved
    game. To move progress, use  Teacher mode >
    Data > Export  on one device and  Import  on
    the other.

  * Clearing the browser's history and site data
    deletes the saved game. Export makes a backup.

  * On iPhones and iPads, Safari can clear a site's
    saved game if it isn't played for about a week.
    Export now and then.


--------------------------------------------------
FOR GROWN-UPS: WHAT IT RUNS ON
--------------------------------------------------

  * Tested in Microsoft Edge and Google Chrome on
    a computer, at phone, tablet and laptop sizes.
  * Not yet tested on real phones or tablets, or in
    Safari or Firefox.
  * The voice comes from the device, so it sounds
    different on each one. The game works without
    it.
  * Plain HTML, CSS and JavaScript. No frameworks
    and no outside downloads. All the characters
    are original drawings.
